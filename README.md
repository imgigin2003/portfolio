# Negin Parseh — Personal Portfolio

This is the repository for my personal portfolio, showcasing my work in AI engineering, backend development, and machine learning. 

## Tech Stack
- **Frontend Framework:** React 18
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Routing:** React Router
- **Animations:** Framer Motion

## Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/imgigin2003/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

## Deployment
The portfolio is designed to be easily deployed on platforms like Vercel or Netlify. It uses standard SPA routing, so ensure your hosting environment redirects all traffic to `index.html`.
